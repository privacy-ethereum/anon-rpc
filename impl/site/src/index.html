anon-rpc

Anonymized RPC for wallets: untrusted, hash-pinned client code in a sandboxed worker, granted a small transport-neutral capability API.

  • Live demo watch an ETH balance through the sandboxed worker
  • Specification the normative SPEC.md
  • @anon-rpc/browser-harness the browser harness on npm
  • GitHub spec, reference implementation, worker template
